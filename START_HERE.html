ShiftConvert

Version 0.2.0 · Windows x64 · All file processing stays on your computer

A first working build. The conversion engine and desktop interface were tested on Linux; the Windows installer was cross-built and inspected, but has not been run on a real Windows PC. The installer is unsigned.

Install and convert

  1. Run ShiftConvert-0.2.0-Setup.exe. It installs for your Windows user, with a Start menu entry and desktop shortcut. Python is included. Target: Windows 10/11 x64; ARM Windows is not validated.
  2. Open ShiftConvert. Drop files into the box, or click Choose files.
  3. Choose an output format. The list contains only formats compatible with every file in your queue. For unrelated files, convert one category at a time.
  4. Optionally tick Maximum file size, then enter a limit in MB or KB. Choose your output folder and click Convert files.
  5. Click Open output folder. Files are saved directly into Downloads by default; existing files are never overwritten. Double-click a queue result for details or an error message.

Files are never uploaded. The app has no account, subscription, telemetry or update requests. Your files remain local unless you choose an output folder synced by a separate service such as OneDrive.

Taskbar and background startup

Right-click the Start menu shortcut and pin it to the taskbar. Pinning keeps the shortcut there without starting the app at sign-in.

Optional background startup can be selected in setup. It starts quietly in the system tray; click the tray icon or open the app again to show the window. With startup enabled, closing the window hides it in the tray. Right-click the tray icon and choose Quit to exit. Change startup in More options. Quit the old version before updating.

Maximum file size

The limit is checked on the actual output bytes, per output file. MB means 1,000,000 bytes; KB means 1,000 bytes. It applies to image and PDF output. A combined PDF must fit the limit as a whole. Files that cannot fit are reported as failures and are not saved.

For images, ShiftConvert tries lower quality where supported, then smaller dimensions if allowed. PNG remains lossless at each chosen resolution. Uncheck Allow smaller image dimensions to preserve pixel dimensions. Very small limits may be impossible.

For existing or document-generated PDFs, normal compression preserves text. To allow more aggressive compression, enable Convert PDF pages to images if needed. This flattens pages and removes selectable text, links, forms and other interactive features. Leave it off when these matter. Image PDFs can lose image quality/resolution to meet a cap.

Maximum file size is not implemented for audio/video, DOCX or data output. Their conversion settings remain available. Stop finishes the current file (or combined PDF) before stopping the queue.

Optional one-time setup

These two large external tools are not included in the installer. The core image, PDF, spreadsheet and media features work without them.

  • Word / Office → PDF: install LibreOffice in its default folder, then restart ShiftConvert. Fonts must be installed locally for matching layout.
  • OCR: follow the Tesseract installation guidance for Windows. Use the default C:\Program Files\Tesseract-OCR location, or add its folder to PATH. Install the English language data (eng); Traditional Chinese needs chi_tra, Simplified Chinese needs chi_sim. Restart ShiftConvert. Choose the matching language in More options. OCR can misread text; review results.

Obtaining optional tools needs an internet connection once; conversion then works offline. The app does not download tools automatically.

Troubleshooting

  • If startup fails, inspect %LOCALAPPDATA%\ShiftConvert\startup-error.txt.
  • If a job fails, double-click its queue row. Unsupported codecs, encrypted PDFs, corrupt files and impossible size limits produce explicit failures.
  • Very large images or PDFs can use substantial memory. Large multi-image PDFs are assembled in memory. Use smaller batches if needed.
  • Conversion is sequential. The progress bar measures completed jobs, not estimated time inside a job.
  • Uninstall from Windows Installed apps. Converted files in your output folder are kept.
